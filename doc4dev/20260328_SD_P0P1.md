## Group 1: ISSUE-002 + 003 (Session Faulted + Error Hint)

### ISSUE-002: ExecutionRouter.fs

**Before (line 37-44):**
```fsharp
let updatedSession =
    { backendSession with
        Status =
            if record.Result.IsSuccess then
                backendSession.Status
            else
                SessionFaulted
        LastExecutionAt = record.CompletedAt |> Option.orElse backendSession.LastExecutionAt }
```

**After:**
```fsharp
let updatedSession =
    { backendSession with
        Status = backendSession.Status
        LastExecutionAt = record.CompletedAt |> Option.orElse backendSession.LastExecutionAt }
```

**理由：** 永遠使用 backend 回報的實際 session 狀態。backend (`GetSessionState`) 才知道 FSI session 的真實狀態。MCP server 層不應自行判斷 faulted — 這是 upstream concern。

### ISSUE-003: McpExecutionTools.fs

**新增 helper (在 formatResultError 附近):**
```fsharp
static member private formatRecordError (fallbackMessage: string) (record: FsiExecutionRecord) =
    let baseError =
        if String.IsNullOrWhiteSpace record.Result.Errors then
            fallbackMessage
        else
            record.Result.Errors

    let context =
        $"[RequestId={record.RequestId}, HostId={record.HostId}, SessionId={record.SessionId}, Backend={record.BackendKind}, ResultId={record.ResultId}]"

    let hint =
        if baseError.Contains("could not be completed due to earlier error")
           || baseError.Contains("Faulted") then
            "\nHint: The session may be in Faulted state. Call reset_fsi_session_routed or create a new session to recover."
        else
            ""

    $"{baseError}\n{context}{hint}"
```

**修改每個 tool method 的 error path（6 處）：**
把 `McpExecutionTools.formatResultError "..." record.Result` 改為 `McpExecutionTools.formatRecordError "..." record`

## Group 6: ISSUE-009 (Max-Retries)

### ProvisioningServices.fs:71-89

**Before:**
```fsharp
let rec pollProcSnapshot
    (procSupervisorClient: IProcSupervisorClient)
    (hostId: string)
    (deadlineUtc: DateTime)
    (isAcceptable: ProcHostSnapshot -> bool)
    : Task<ProcHostSnapshot option> =
    task {
        if DateTime.UtcNow >= deadlineUtc then
            return None
        else
            ...
            do! Task.Delay 250
            return! pollProcSnapshot procSupervisorClient hostId deadlineUtc isAcceptable
    }
```

**After:**
```fsharp
let rec pollProcSnapshot
    (procSupervisorClient: IProcSupervisorClient)
    (hostId: string)
    (deadlineUtc: DateTime)
    (isAcceptable: ProcHostSnapshot -> bool)
    (remainingAttempts: int)
    : Task<ProcHostSnapshot option> =
    task {
        if DateTime.UtcNow >= deadlineUtc || remainingAttempts <= 0 then
            return None
        else
            ...
            do! Task.Delay 250
            return! pollProcSnapshot procSupervisorClient hostId deadlineUtc isAcceptable (remainingAttempts - 1)
    }
```

**Callers:** Pass `maxAttempts = 60` (15s / 250ms).
