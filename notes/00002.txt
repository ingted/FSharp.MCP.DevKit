  - 多個 #r / open 放同一 block 時，失敗模式不可預測，agent 只能高成本 bisect。
  - async 下 printfn / stdout 不穩定，讓 probe/health-check 難做。
  - path mapping / mount mapping 不自描述，整合環境下很容易靠猜。
  - # / " 很多是否會讓 tool-call JSON 壞掉，現在只能列為懷疑，還不是已證實根因。
